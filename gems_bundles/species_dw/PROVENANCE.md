# gems_bundles/species_dw/species_dw.json — provenance

- **What**: per-species aqueous tracer/self-diffusion coefficients at 25 C
  (m^2/s) with ionic charges, parsed from the `-dw` entries of the
  SOLUTION_SPECIES block of `phreeqc.dat`, plus a hand-curated `aliases`
  map from GEMS DC names to phreeqc.dat species names. Data source only —
  no PHREEQC code runs in Tier 0 (spec TINN_RT_phreeqc_tiers_spec §2.2).
- **Source**: `phreeqc.dat` as shipped with the phreeqpython 1.6.2 package
  (USGS PHREEQC distribution database; 56 `-dw` entries).
  source sha256: `6bb5ebc1d0ecca0e921c13a2241d05d3a3333b142d1d740b2ed03a786442bdf5`
- **Generated by**: `scripts/make_species_dw_table.py` (deterministic:
  sorted rows, no timestamps; an existing `aliases` block survives
  regeneration — it is curated data, not derived data).
- **Aliases policy**: identities only (same solute, different naming
  convention, e.g. `SiO2@` = `H4SiO4`, `Ca(SO4)@` = `CaSO4`). GEMS
  complexes with no phreeqc analog (CaOH+, AlO2-, silicate complexes,
  Fe(III) species, ...) are deliberately unmapped: they take the config's
  explicit `default_dw_m2_s` and are listed in the run summary, or the
  run refuses when that field is null. No silent defaults.
- **Temperature**: values are 25 C; the engine applies the Stokes-Einstein
  correction `D(T) = D(298.15) * (T/298.15) * (eta(298.15)/eta(T))`
  (transport.stokes_einstein_factor) and records the factor in the summary.
- **Cite**: Parkhurst & Appelo (2013), Description of input and examples
  for PHREEQC version 3, USGS Techniques and Methods 6-A43 (the `-dw`
  compilation); CRC Handbook limiting ionic diffusivities lineage.
- **Audit rule**: read-only input; scripts must never mutate it. The json
  embeds the source sha256; regenerate only via the generator.
